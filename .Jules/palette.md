## 2026-10-22 - Replaced Native Alert with Inline Validation\n**Learning:** Relying on native `alert()` for form validation interrupts the user's flow and can be frustrating. Moving to inline validation with `aria-live` provides a much smoother experience while retaining critical a11y compliance for screen readers.\n**Action:** For all future client-side validations in this app, avoid `alert()` and default to conditionally rendered, inline error blocks properly connected to the inputs via `aria-describedby`.
