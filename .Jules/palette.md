## 2024-10-27 - Inline Form Validation Replacement for Native Alerts
**Learning:** Replacing blocking `alert()` dialogs with inline validation using `aria-live` regions significantly improves the non-visual user experience. When standard validation errors are presented visually, linking them to inputs with `aria-describedby` and handling state with `aria-invalid` provides an immediate and clear path for screen reader users to understand and rectify form errors. Furthermore, native `alert` messages interrupt flow, are often poorly styled by browsers, and can be inaccessible.
**Action:** Default to inline, non-blocking error messages for all form inputs. Pair these with `aria-live="assertive"` for the error container and `aria-invalid` on the input element. Use input event listeners to clear error states natively as the user types.
